# Summary
`lobshot-lab`: headless balance runs and an interface for LLM agents to play turn by turn.

# Problem
Balance across 18 mobiles can't be judged by hand, and qualitative playtesting by agents needs a
stable way in that sees only what a player sees.

# Goals
1. A balance run reports every matchup's win rate.
2. An LLM agent (e.g., through MCP) can play a full game.

# Technical Approach
See `DESIGN.md`, "Bots and the lab". The controller trait from M2 is the seam: SearchBot, a remote
human and an external agent all implement it.

# Assumptions
- SearchBot from M2 is good enough to make win rates meaningful.

# Constraints
- Balance runs are CPU-bound; they parallelize across games, never inside one.

# References to Code
- `crates/lab/`, `crates/sim/`.

# Non-Goals (MVP)
- Automatic tuning: the lab reports, people change `sim::tuning`.

# History
- 2026-10-19: Created from DESIGN.md's milestones.
- 2026-10-21: Started. Aaron's picks: agents play headless in the lab (not live rooms), get a trace
  tool (where a shot would land under the wind the HUD shows, what SearchBot already knows), and
  connect through any MCP client (the lab holds no API key); balance runs are 1v1 between Normal
  bots on every map and variant, seats swapped. First, one referee in `sim` for every host: the
  server, practice mode and the lab roll and stamp alike, and the map loader moves to
  `lobshot-assets` so the lab needn't depend on the server.
- 2026-10-21: T-001 to T-004 done. uat-002's command runs in release: a balance run is 3000 games.
  The first runs (200 a matchup, seed 1) disagree by level: with Normal bots Hookclaw wins 26% (its
  shots are the most wind-sensitive, and Normal misreads the wind), with Hard it wins 67%; five
  matchups leave 35-65% under Normal, eight under Hard. On Ashspine A, Hard bots hurt the enemy
  with 14% of their shots (43 to 87% elsewhere): SearchBot never walks, and the ridge often leaves
  it no shot.
- 2026-10-21: T-005 done; uat-003 passes (a scripted agent plays whole games over MCP and over the
  CLI). The MCP server is written out over JSON-RPC rather than with the rmcp SDK, which would bring
  tokio into a synchronous crate. Agent turns are charged the bot think time. On
  the way, a fix for the live server: a shot's power above four bars no longer decodes.
- 2026-10-21: T-006 done. A fresh agent played three duels over the CLI and wrote the first report.
  Its trace matched every shot it fired. Its interface findings are fixed (trace fires the way you
  face, a clearer log and view, the items' numbers in the rules), as is a Bionic Heal floored to
  169 of 1000 HP by float shares. Its game findings stay open: the Ashspine spire against 60-degree
  aim caps, a Mirror that misses shots fired close to it, Power Up and Sparkhorn's side bolt, and
  bots that never walk. `cargo make uat` (uat-001) and the balance run (uat-002) pass on 7d0300b;
  M4 is done.
