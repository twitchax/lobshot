# Summary
The complete Solo game, the first version worth sending to friends, deployed at
`lobshot.twitchax.com`.

# Problem
M2's 1v1 has one mobile and no items. Solo with teams, items, sudden death and five mobiles is the
smallest game that plays like GunBound, so it is the first deploy.

# Goals
1. A 4v4 Solo game with mixed humans and bots plays to the end.
2. Five mobiles, five maps, all items.
3. Friends can play from a link on the public site.

# Technical Approach
See `DESIGN.md`, "Scope", "Rooms" and "Deployment". Item and mobile behaviors are functions in
`sim` driven by the tuning table, so the lab can exercise them headless.

# Assumptions
- The Docker image from M0 is the deploy artifact.

# Constraints
- One Fly machine, `--ha=false`; DNS-only (grey cloud) CNAME on Cloudflare.

# References to Code
- `crates/sim/`, `Dockerfile`, `assets/`.

# Non-Goals (MVP)
- Score, Tag and Jewel (M6); the remaining mobiles, weathers and maps (M5).
