# Summary
The other 13 mobiles, the remaining weathers and the last five maps: the whole GunBound roster in
original designs.

# Problem
M3 ships five mobiles. "True to GunBound" means all of them, including the ones with their own
engines (Raon's mines, Aduka's satellite, JD's pull and push, Nak's digging).

# Goals
1. 18 selectable mobiles plus Random.
2. Every GunBound weather.
3. Ten maps, twenty variants.

# Technical Approach
Each shot engine is a behavior function in `sim`, tuned in `sim::tuning` and exercised by the lab
before it ships. Art follows the spike's pipeline, about 1 to 2 hours of agent time per mobile plus
review.

# Assumptions
- The lab (M4) catches broken matchups before players do.

# Constraints
- Original names, silhouettes and map layouts only.

# References to Code
- `crates/sim/`, `assets/`.

# Non-Goals (MVP)
- Score, Tag and Jewel (M6).
