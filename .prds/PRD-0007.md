# Summary
GunBound's other three modes.

# Problem
Solo is one of four GunBound modes; "all of the GunBound modes" was the call.

# Goals
1. Score, Tag and Jewel are room options, each playable with humans and bots.

# Technical Approach
Modes are rules in `sim` over the same turn order, so replays, bots and the lab work unchanged.

# Assumptions
- The research's GunBound mode rules (mechanics.md section 7) are accurate enough; gaps get a
  recorded pick.

# Constraints
- None beyond M5's.

# References to Code
- `crates/sim/`.

# Non-Goals (MVP)
- DragonBound-only modes (Battle Royale, Boss).

# History
- 2026-10-19: Created from DESIGN.md's milestones.
- 2026-10-24: Active. T-001 (Score) goes first and lays what every mode shares: the mode as a room
  option, the game's end decided per mode, and respawn at a picked drop point. Tag and Jewel follow
  on it once M5's roster has merged, so Jewel's no-damage rule covers every new shot. Each mode
  brings its own share of T-004 (bots playing the objective).
